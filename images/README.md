# Image Assets for Jennifer Olisakwe Portfolio

Place visual assets in this folder using the following file names:

- `profile.jpg` — your circular profile photo for the About section
- `mediflow-preview.jpg` — screenshot or visual preview of the MediFlow AI project
- `osteo-preview.jpg` — screenshot or visual preview of the OsteoDetect project
- `hero-composition.jpg` — optional hero artwork if you want to replace the CSS illustration

## Notes

- The portfolio currently uses CSS backgrounds for the hero and project previews when images are not available.
- If you add `mediflow-preview.jpg` and `osteo-preview.jpg`, those images will display in their project cards and case study pages.
- You can replace the `hero-composition.jpg` image later by updating the hero section markup and styles.
