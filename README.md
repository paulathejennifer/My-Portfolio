# Jennifer Olisakwe Portfolio

A modern dark-themed portfolio website for Jennifer Olisakwe, featuring two featured projects: MediFlow AI and OsteoDetect.

## Features

- Single-page layout with smooth scrolling navigation
- Animated hero section with floating laptop and cup vignette
- Sticky top navigation with active section highlight
- Skills section with tabbed categories: TECH, DBMS & CLOUD, AI, TOOLS
- Project showcase for MediFlow AI and OsteoDetect only
- Contact form and social links
- Responsive mobile layout with hamburger navigation

## Files

- `index.html` — main portfolio page
- `styles.css` — dark theme styles, gradients, glow effects, and responsive layout
- `script.js` — mobile menu toggle, nav active state, and skills tab filtering
- `mediflow-case-study.html` — MediFlow AI case study page
- `osteo-case-study.html` — OsteoDetect case study page
- `images/` — image assets folder and guidance file

## Run locally

1. Open `index.html` in your browser.
2. Add `resume.pdf` to the project root if you want the resume button to work.

## Notes

- The `ALL PROJECTS` button links to the GitHub repositories page for Jennifer Olisakwe.
- The project cards link to dedicated case study pages for MediFlow AI and OsteoDetect.
- Place visuals in `images/` with the filenames described in `images/README.md`.
- The contact form is configured as a `mailto:` fallback for quick prototyping.
